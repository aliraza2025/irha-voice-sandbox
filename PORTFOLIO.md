# Portfolio card

**irha Voice Sandbox**

Category: Voice AI

Stage: Independent prototype

Role: Product design and development, with AI-assisted implementation

An independent public sandbox for local speech transcription, service intake, clarification, quote review, and human handoff using fictional records.

Verification: Local Whisper transcription and LiveKit toolset.

Repository: https://github.com/aliraza2025/irha-voice-sandbox

Demo: https://aliraza2025.github.io/irha-voice-sandbox/

Scope qualification: A local English synthetic recording was transcribed successfully. The LiveKit Agent class and quote tool were instantiated, but no live room, telephony call, or external booking was tested. The browser microphone and local speech controls depend on browser support. This sandbox is not the commercial irha service implementation.
